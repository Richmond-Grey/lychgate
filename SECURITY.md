# Security Policy

## Project status

Lychgate is **pre-1.0**. It is a personal open-source project under active development, and it has
not had an independent security audit. Breaking changes may land in any `0.x` release. Please weigh
that before using it to protect anything important.

## Supported versions

Only the latest published `0.x` release receives security fixes. Older versions will not be
patched.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" under this repository's **Security** tab).

Helpful details to include:

- The affected package(s) and version(s)
- A description of the issue and its impact
- Steps to reproduce, or a minimal proof of concept
- Any suggested fix, if you have one

## What to expect

- An acknowledgement within 7 days.
- An assessment and, where confirmed, a fix timeline as soon as practical. This is maintained by one
  person in their spare time, so please allow some patience.
- Credit in the release notes and advisory, unless you would prefer to stay anonymous.

Please give a reasonable window to release a fix before any public disclosure.
